# CHRONOS (Français)

Moteur d'exécution temporelle et de reconstruction pour le reverse debugging.

- Enregistrement réel via ptrace.
- Voyage temporel, checkpoints, diff d'états.
- Interface Qt6 et CLI.
- Format binaire v2 avec compression zstd.
