# CHRONOS (Español)

Motor de ejecución temporal y reconstrucción para reverse debugging.

- Grabación real con ptrace.
- Navegación temporal, checkpoints, diff de estados.
- GUI Qt6 y CLI.
- Formato binario v2 con compresión zstd.
