# CHRONOS (Deutsch)

Temporale Ausführungs- und Rekonstruktions-Engine für Reverse Debugging.

- Echte Aufzeichnung via ptrace.
- Zeitreise, Checkpoints, Zustands-Diff.
- Qt6-GUI und CLI.
- Binärformat v2 mit zstd-Kompression.
